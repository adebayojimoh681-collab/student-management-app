# 🎓 EduTrack • Mobile-Friendly Student Management App

A responsive, high-performance, mobile-first Student Management Web Application built with modern HTML5, CSS3, and JavaScript.

## 📱 Features

1. **🔐 Authentication & Login**:
   - Secure Student ID / University Email and Password sign in.
   - 1-Click Quick Demo Login for instant testing (`Alex Johnson - Computer Science`).
   - "Remember Me" and "Forgot Password" dialogs.

2. **📊 Student Dashboard**:
   - Welcome banner with student name, avatar, honors status, and credit completion progress bar (e.g. 76/120 credits).
   - High-level metric cards: Cumulative GPA (3.84), Enrolled Courses (4), Attendance Rate (94%), Current SGPA (3.88), Fee Payment status.
   - Quick Action buttons: Courses, Results, Print Report, Profile.
   - Today's Classes preview with class timings, classroom numbers, and instructors.
   - Upcoming deadlines and examination schedules with category badges (Exam, Project, Quiz, Assignment).

3. **📚 Course Management**:
   - Real-time search filter by course code, title, or instructor.
   - Segmented tab views: **"My Enrolled Courses"** vs. **"Course Catalog"**.
   - Course cards with credit breakdown, progress meters, room locations, and schedules.
   - Interactive Course Syllabus modal with weekly breakdown.
   - Live **Enroll** and **Drop** course functionality with immediate credit recalculation and local persistence.

4. **📈 Results & Academic Grades**:
   - Interactive GPA Gauge displaying CGPA and SGPA.
   - Academic Term dropdown selector (Fall 2026, Spring 2026, Fall 2025).
   - Subject-wise breakdown displaying Internal Marks, Exam Marks, Total, and Grade Badges (`A+`, `A`, `A-`, `B+`).
   - **Target GPA Simulator**: Calculate required SGPA in upcoming semesters to achieve target honors.
   - Print & PDF Export ready Grade Sheet.

5. **👤 Profile Page**:
   - Full student identification header with avatar and ID card badge.
   - Personal details: Campus Email, Phone, Date of Birth, Emergency Contact, and Residence Address.
   - **Edit Profile Modal**: Modify personal details with instant LocalStorage updates.
   - Academic details: Faculty / Department, Academic standing, and Advisor name.
   - Settings: Dark Mode toggle, Demo Data reset, and Sign Out.

6. **📲 Mobile UX Highlights**:
   - iOS & Android native-feeling bottom navigation bar with active indicators.
   - Responsive layout supporting both mobile screen dimensions and tablet/desktop wide view (toggleable via the top navigation bar).
   - Bottom sheet modals with smooth slide-up animations.
   - Floating toast notification system for instant feedback.
   - Dark theme & Light theme with automatic persistence.
